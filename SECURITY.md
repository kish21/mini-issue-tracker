# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of this software seriously. If you find any vulnerability:
1. Please do NOT file a public issue.
2. Report the vulnerability privately via email or private repository advisory.
3. Provide a clear description, reproduction steps, and potential impact.

We will acknowledge reports within 48 hours and work on a fix promptly.
